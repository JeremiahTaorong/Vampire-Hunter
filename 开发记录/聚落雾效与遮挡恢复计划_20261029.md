# 聚落场景雾效、体积光与遮挡渐隐恢复计划

用户于 2026-10-29 明确要求实施；本文件将此前聊天中的计划落盘。后续追加要求：村庄灯默认开启。

## 目标与依据
以 Claude 完成的 PrologueSettlement 为目标，迁移 PrologueCarriedDarkReview 中获用户“雾气效果非常完美”认可的浓黑体积雾、随身暖光、MicroAVL 光晕和局部减雾；恢复树木和灌木遮挡镜头时的渐隐。

## 实施内容
1. 保存场景、构建器、README、开发记录和验收清单的时间快照；检查未保存场景。
2. 为聚落复制认可版本的 Pipeline、Renderer Feature、Volume Profile 和雾 shader；关闭普通距离雾，保留聚落后期效果。沿用当前灯笼实体及认可版本随身光、光晕、减雾参数。
3. 新建聚落多灯减雾管理器与灯组件，容量 64，超限报错。普通局部灯内外半径分别为范围的 15% 和 45%，中心保留 35% 雾密度；玩家沿用原参数。区域重叠取最强减雾，灯开关与强度平滑驱动效果，方向光不生成清雾球。全部村庄灯默认开启。
4. 植被按整株及全部 LOD 同步渐隐，最低可见度 0.18，速度每秒 3；停用或失去目标后恢复。为 URP Lit 和 CTI 保留原纹理、法线、风动及光照并加入渐隐，不加入虚化。
5. 构建器接入相同安装逻辑，本轮直接迁移现存场景，不重新生成造景。

## 最小验证
Unity 编译与保存；对比认可雾参数；登记全部局部灯；固定村口、广场、林缘机位渲染；开关灯及同照明下减雾开关对比；人工构造遮挡并确认渐隐和恢复；重新加载核查材质覆盖；确认地形、导航、旧认可场景及原有对象位姿未变。

不进行完整走图、真实键鼠、战斗或帧率测试。截图和人工构造检查不代表全流程或用户视觉验收。
