## 三、哪里出了问题，以及实际尝试

### 1. 没有 Blender，先解决上传格式

本机没有 Blender。Mixamo 上传界面实际列出了 FBX、OBJ、ZIP，因此采用本地 GLB → OBJ + MTL + 贴图 → ZIP 的替代路径，没有安装软件，也没有经过第三方格式转换网站。

此路径已成功把角色带到 Mixamo 的朝向与关节标记步骤；本轮没有生成上传用 FBX。上传副本保留原有站姿，没有实际调整成 A-Pose/T-Pose。

### 2. Safari 的模型画布持续空白

Safari 已登录 Mixamo，完整 ZIP 上传处理后能进入 Orient 和 Place markers，但角色画布始终空白。此时无法可靠定位下巴、手腕、肘、膝与骨盆，因此没有在 Safari 盲放标记。

额外打开 WebGL 检测页，其文字提示浏览器支持 WebGL；这不足以确定 Safari 画布空白的底层原因，**不能据此断言 Safari 完全不支持 WebGL**。

随后使用本机已有 Chrome。Chrome 初始未登录，按用户要求由用户自行登录；用户回复“已在 Chrome 登录 Mixamo”后才继续。没有操作账号密码或验证码。

### 3. Chrome 可以显示模型，但服务器自动绑骨失败

在 Chrome 上传相同完整 ZIP 后，实际看到帽子、长风衣、手套、腰带、武器、双腿完整显示，人物正面朝前。

标记依据可见身体位置放置，并启用左右对称：下巴、双手腕、双肘、双膝、骨盆。首次采用 Standard Skeleton（65）。

完整模型共发起了三次自动绑骨请求：标准骨骼尝试及重试；另一次尝试切换 No Fingers（25）以排查手套/手指影响。均未进入成功后的绑定角色预览。错误返回后界面重置为标准骨骼；没有保存每次请求的完整参数与响应，因此不能为每次请求分别断言独立错误码或实际最终骨骼数量。随后曾单独确认 No Fingers（25）选项可选，但没有获得该配置的成功结果。
