## 总体空间

- 地图参考约 120 × 64 Unity 单位；世界坐标换算以实际地面边界为准，不把参考图的估算坐标当作实测。
- 左半：村口、广场、住宅和工坊；建筑围绕广场与道路形成聚落。缩放建筑时统一以玩家高度、门高和建筑实际包围盒为依据，不按包围盒最大边一律缩放。
- 右半：密林主体。沿地图北、南及远端保持连续树冠；中央道路从村庄过渡到森林，局部清理形成入口，不大面积清空森林。
- 交界：森林向村边渗透，保留低矮草、灌木、几株树和木屋，但广场及主要行走区域不被高树覆盖。

## 地表与道路

1. 村庄广场采用偏灰褐色土石地面，边缘过渡至杂草和落叶；井或公共设施作为中心地标。避免使用大面积规则几何色块表现最终道路。
2. 村口至广场的路保持约 5–6 单位可通行宽度；广场与支路自然衔接，路径形状参考图中的弯曲轮廓。住宅门前留出约 3 × 3 单位空间。
3. 从广场向右的道路逐渐变窄、变暗，进入森林后以 Forest_Road 候选纹理、泥土和落叶混合；路边加入小石和低草，但不要遮住路线。
4. 森林地面以 Forest_Ground 和 Forest_Leaves 为候选，少量 Forest_GreenGround 用于潮湿边缘。先做小面积材质样片，确认色彩、比例、法线和 URP 表现，再决定地面实现方式。

## 植被分区

| 区域 | 布置策略 | 可用资源 |
|---|---|---|
| 村口与广场 | 保留开阔通行面；边缘、围栏后、建筑后方用成簇草和灌木，不在广场中央放高树 | Mugwort、JapaneseEurya、JapaneseLaurel、grass01、Rock A–D |
| 村庄外围与房屋后方 | 中低密度向林缘渐变；局部树冠包围住宅但不穿过屋顶 | Pine、JapaneseCedar、JapaneseCypress；小型针叶树 |
| 森林入口 | 两侧密植形成框景；保留约 5–7 单位净宽，地面点缀落叶与岩石 | Conifers Medium/Small、FallenLeaves、Rock、Decayed wood |
| 森林内部 | 高、中、小树混合，树冠错层并保持密度；留出玩家路径和调查空地 | Conifers Tall/Medium/Small，少量 Bare；Pine、枯木和灌木 |
| 边缘远景 | 密集树冠遮挡地图边界，结合 LOD 和适当距离 | Conifers LOD、既有 Pine Forest 素材 |

密度以实际俯视图和游戏镜头调节，不预先假定每平方米数量。树木避免与屋顶、道路及关键线索相交；仅局部清理，不删除整个区域。倒木不得堵住主路。

## 建筑与可交互灯光

按用户参考图的 B1–B12 建筑类型和相对位置重建，保持村口、广场、旅店、工坊与林缘住宅之间的关系。图中文字坐标与图像示意存在偏差时，先制作带编号的实际俯视对照，明确差异后再细调。逐栋确认模型直立、门朝向、落地、人与门的比例、碰撞及摄像机遮挡。

旅店和广场保留暖光作为引导；少数住宅和工坊可用靠近后切换的灯。森林逐渐减少人工光，手灯始终足以识别路径及必要线索。所有灯光参数须在实际游戏画面调节；不要把装饰灯作为获得必要线索的唯一条件。

## 实施与验证顺序

1. **素材样片**：分别导入并记录包、版本和管线；验证 Conifers 的 URP 子包、Fantasy shader、Essential 材质和 Terrain Layer。检查粉色材质、树叶透明、风、LOD、碰撞和性能。保留原场景及导入前备份。
2. **建筑与路线**：以参考图为蓝本搭建左村右林，逐栋检查方向与比例，修正入口和广场。检查建筑和路之间的净空。
3. **地表**：确定 Terrain 或兼容地面方案，制作不规则道路及广场，验证纹理比例和过渡。
4. **植被**：保留右侧高密度森林，逐层增加林缘、灌木、草、岩石与倒木。仅清理建筑包围盒、主要路线和关键调查空间。
5. **光照与交互**：调整手灯、村庄灯光与雾，保证近黑氛围下仍能看见建筑和路线；验证灯具不会与其他 E 键交互冲突。
6. **验收证据**：导出实际 Unity 同尺度俯视图，与参考图逐项对照；在 Game 视角从村口走至广场、各线索和森林入口，检查碰撞、可见性、灯光切换、导航与帧率。记录测试条件和未通过项；未完成走图前不得称为完成。
