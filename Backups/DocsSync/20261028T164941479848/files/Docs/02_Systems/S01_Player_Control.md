## 1. 目标体验与范围

玩家主要用鼠标点击探索和攻击，以 WASD 即时躲避/调整位置；技能瞄准与普通攻击锁定分离。任何自动行动都应让玩家清楚知道当前目标、停止原因和恢复条件。

S01 负责输入含义、目标选择、移动/追击/就地普攻的转换、互动发起、Dodge 与技能方向的操作规则。
伤害、动作释放/冷却/打断细节由 S02；形态可用性由 S03；谜题与精华结果由 S08；通路与障碍由 S07；具体界面布局由 S11；镜头遮挡和视角由 S13。本稿只定义玩家行为。

## 3. 操作与目标识别

### 3.1 冻结操作含义

| 操作/事件 | 结果 | 条件与限制 |
|---|---|---|
| 左键地面 | 清除旧追击目标，向点击地点移动 | UI 未阻挡；其他动作限制仍生效 |
| 左键有效敌人 | 锁目标、靠近、范围内持续普通攻击 | 不自动释放 A/B；目标失效、切换或取消时终止 |
| WASD | 接管移动，终止当前自动路程并暂停普攻，保留目标 | 不能用移动输入主动取消正在进行的治疗 |
| 松开全部 WASD | 不恢复旧路；目标合法且在当前攻击范围内才恢复普通攻击 | 目标在范围外仅保留目标 |
| 左键普通互动对象 | 自动靠近，合法互动范围内执行 | 具体资格/结果由 S08；不能隔墙触发 |
| 左键尸体精华 | 只选择并靠近 | 不自动吸收；Human 不可吸收 |
| 范围内长按 E | 发起精华吸收 | F09 冻结 E；成功/被有效攻击打断/死亡结束 |
| Skill A | 以鼠标落点指定范围位置 | 圣水/血爆的可释放范围和合法落点细节待 S02 |
| Skill B | 朝鼠标方向；指向有效敌人时精准朝该目标 | 无指向敌人时不自动转向旧锁定目标 |
| 药剂/血液再生 | 各自独立发起治疗 | 形态、库存、BP、冷却等资格满足后才能开始 |

识别优先级【冻结摘录】：阻挡输入的 UI → 有效敌人 → 明确互动对象/精华 → 地面。同优先级对象重叠时的选择方式尚未冻结（Q6）。不可用对象应给出条件反馈，不能假装成功。

## 4. 移动、追击与恢复

### 4.1 正常点击循环【冻结摘录】

点有效敌人 → 追击到普通攻击范围 → 按正常攻击间隔连续普攻。正常点击追击中，敌人离开范围且玩家未用 WASD 接管时继续追击。点击其他敌人换目标，点击其他地点清旧目标并开始新行动。不通过恢复普攻刷新攻击间隔。

### 4.2 WASD 接管【冻结摘录】

一旦按下 WASD，就结束当前自动路程、暂停自动普攻并保留目标。松开时只看当前范围：在范围内就地恢复普攻，超范围不追。不得在玩家松手后突然返回旧目的地。
“即时接管”是对自动行动的优先权，不赋予主动取消技能、Dodge、受击或治疗的权限。受限制动作期间可否缓冲输入等见 Q4，不能自行补成无条件自由移动。

### 4.3 恢复边界

- 技能 A/B 结束：若合法目标在普通攻击范围内且无 WASD，则恢复普攻（F13）；不得刷新普通攻击间隔和技能冷却。
- 技能结束时目标在范围外：F13 未规定是否恢复技能前追击，留待 Q3，不能以“自动攻击恢复”自行补追击。
- WASD 松开后已在范围内恢复普攻，目标随后又移出范围：GDD §4.1 的一般追击规则与 F07 的“初次松开不恢复旧路”需明确衔接。本稿倾向此时按正常普攻循环重新追击，但这是【落实解释·待审：Q3】，不能声称已独立冻结。
- 目标死亡、消失或不再有效：终止对它的攻击/追击（F06）。不自动更选最近敌人属于【落实解释·待审：Q6】。
- Dodge/治疗/受击结束后是否自动恢复攻击、何时允许新动作：冻结文本没有完整细则，见 Q3/Q4，不借 F13 扩大适用。

## 5. 交互与可达性

【冻结摘录】普通互动点击后自动靠近执行；精华点击只靠近/选中，必须长按 E 才吸收。吸收引导启动后不能通过松开 E、移动、技能、Dodge 或取消键主动结束；有效受击与死亡仍可终止。其他普通互动是否有演出锁定由 S08/S09 定义，不能把所有互动都视作不可取消治疗。

【冻结摘录】没有完整可走路线时，尝试到最近的安全且真实可达位置，提示无法直接到达；到最近点后停止。锁门、书架、悬崖和敌方阻挡不能被“最近点”绕过发生非法攻击/互动。若不存在安全可达位置，原地停止并说明原因，是 F36 的【落实解释·待审】。

旋转书架改路后旧路线失效，也要满足以上停止条件（F14/F36、T13）。具体书架状态及解法由 S08，S01 不自行设定。

【提案·待审】不可达后的自动行动已停止，保留目标但显示不可达标识；通路后来恢复也要新点击才重新靠近，避免突然自行行动（Q6）。这不限制玩家正常 WASD 操作。

英文反馈候选（均为草案，交 S11 最终排版）：`Target unreachable`、`Hold E to absorb`、`Cannot use in this form`。Human 不显示 BP/C，也不能为了反馈而提前暴露相关资源条（F26）。

## 6. 动作限制与并发边界

| 当前行为 | 操作/事件 | 已确定结果 | 尚待细化 |
|---|---|---|---|
| 自动寻路/普攻 | WASD | 中断自动路程、暂停普攻、保留目标 | 同时新点击见 Q2 |
| 正在技能 A/B | 动作结束 | 按 F13 条件恢复普攻 | 与其他新输入的打断/缓冲见 Q4 |
| 正在技能/Dodge/治疗 | 普通攻击请求 | 不得同时产生普通攻击伤害 | 是否缓存见 Q4 |
| 任一治疗引导 | 移动、技能、攻击、Dodge、释放 E、取消键 | 不能主动取消；三治疗互斥 | 恢复行动见 Q3 |
| 任一治疗引导 | 有效受击 | 打断，不扣费不恢复 | 受击后的普通攻击恢复见 Q3 |
| 技能正式释放前 | 有效受击 | 未释放动作打断，不付 BP/C/CD | 具体释放点由 S02 |
| 技能正式释放后 | 有效受击/形态变化 | 已释放攻击继续，不回滚既有效果 | 后续动作限制由 S02/S03 |
| 任何行为 | 死亡 | 终止行动，按 S12 失败/检查点规则恢复 | 重生后不恢复旧路/锁定为提案 Q6 |
| UI 阻挡 | 世界点击 | 不发生穿透的移动/攻击/互动 | UI 打开是否暂停由 S11，不自行决定 |

这不是所有动作之间的总优先级表；未定的抢占关系必须由 S02 协作确认，不能补一套未经批准的战斗取消规则。

## 7. Dodge、技能瞄准与参数

【冻结摘录】Dodge 短距离、防御性、不耗 BP、不加污染；无敌窗口明显长于 Skill B 起步窗口。Skill B 较长且为攻击冲刺；Silver Dash 沿途圣伤，Blood Mist Dash 穿敌并沿途血伤。08 特定血锁仅允许指定 Blood Mist Dash 机制通过，其他实体墙不因血雾任意穿越；普通 Dodge 不能替代血锁机制（GDD §5.3、F16）。
【提案·待审：Q5】Dodge 有 WASD 方向时按该方向，无 WASD 时朝鼠标方向；鼠标恰在角色位置时沿当前朝向。这个方向优先级尚未冻结。
【待细化 O-04】移动速度、普通攻击范围、互动范围、Dodge 距离/时长/冷却、Skill B 距离及两者无敌窗口的具体数值未定；本稿仅保留上述相对关系，不把试验值写成正式参数。
【待细化】A 超出施放范围、落在墙外或不可用区域的处理，以及 B 指向目标已移动时的方向取样，留给 S02 联合审阅；不能默认会自动走到施法点或穿墙命中。
