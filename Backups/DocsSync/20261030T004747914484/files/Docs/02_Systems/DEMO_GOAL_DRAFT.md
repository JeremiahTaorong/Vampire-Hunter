设计依据：根目录 GDD v4 §§1–6、§10；Decision Register F01–F38；Narrative v2；原始 System Coverage Matrix §1/§7/§9。R70/R73 的 Phase 1 是独立序章、墓穴、导师 Boss 原型；正式主线、八房及三结局仍属 Phase 2，不删减冻结范围。原始基准不修改。

## Demo 结构：待审提案

主菜单提供 Prologue、Crypt、Mentor Boss、Controls、Quit；三个章节使用独立入口和预设起始状态，不冒充正式主线连贯进度。菜单、说明和游戏文字使用英文（F27）。

| 章节 | 玩家目标与主要流程 | 基准与系统 |
|---|---|---|
| Prologue | 村庄现场物证→NPC 证词→简单推理→森林外围猎杀→导师线索；Human 阶段练习移动、普攻、Dodge。目标 5–8 分钟，需试玩测量 | R04/R53/R56/R59；S01/S02/S05/S09 |
| Crypt | 主动调查古血印→剧情感染→揭示 BP/C→使用 Blood Burst、体验敌人和治疗/精华；结束后可重试或返回菜单 | R04/R27/R33/R43；F02/F09/F15/F26；S01/S02/S03/S04/S08/S11 |
| Mentor Boss | 战前装备/最低 BP 保障→导师猎人阶段→血爪、血雨、血锁阶段→Blood Mist Dash 穿指定血锁→胜利或检查点重试 | R24/R29/R30/R58/R72；F05/F12/F16/F19；S02/S04/S05/S06/S12 |

墓穴及 Boss 各约 3–8 分钟仅为估计，尚无试玩依据。Boss 入口预设不代表正式剧情中已完成战前选择；Demo 胜利可显示完成提示，不假称三结局已实现。基础镜头为固定斜俯视跟随，画风为风格化哥特（F24/F25）。

| 功能 | 玩家可验证的结果 | 来源/计划验证 |
|---|---|---|
| 移动与攻击 | 点击地面移动，点击敌人追击并连续普攻；WASD 接管、暂停攻击并保留目标，松开遵守 F07 | R74/R78/R81、F06/F07；S01 待审 |
| Dodge 与技能 | 防御闪避；A 根据鼠标落点、B 根据鼠标方向或有效目标；Dodge 无敌窗口长于 B 起步 | F05/F08/F12；T12 未执行 |
| 互动与治疗 | 点击普通对象靠近互动；精华靠近后长按 E；治疗互斥、不可主动取消、受有效攻击可中断 | R33/R37/R41/R44、F09；T11 未执行 |
