## 1. High Concept 与游戏闭环【已确认】

玩家扮演不具名的吸血鬼猎人，调查村庄失踪案并寻找失联导师 **Elias Voss（暂用姓名，F20）**；在古堡被迫感染后，玩家通过战斗、探索、净化和能力选择处理 Blood 与 Corruption，最终面对已经堕落的导师。古堡中的外部压力不可避免，但玩家仍对后续选择负责。

**核心循环**：获取线索 → 解锁空间/战斗 → 使用 HP/BP/C 资源 → 选择圣/血成长和净化 → 取得解药碎片 → 进入下一主线或可选回溯 → 战前接受/拒绝 → 两阶段 Boss → 三结局。

- 类型：单人、3D 资产 + 2.5D 固定斜俯视、剧情导向 ARPG + 探索解谜；Diablo 式点击移动/攻击/互动与 WASD 手动接管共存。
- 视听：**Stylized Gothic Dark Fantasy**，风格化哥特暗黑，使用轮廓、红/金/冷蓝灯光营造差异（F24）；英文 UI、字幕和日记（F27）；关键事件短过场/字幕/环境音+BGM，**不要求完整配音**（F28）。
- 镜头：跟随角色的固定约 40–50° 俯视角，有限缩放，无自由旋转（F25）；具体角度与镜头遮挡策略可测试调节。
- 叙事：环境线索、关键日记、短 NPC 对话、重要剧情演出（F23）；不依赖全程配音。

| 06 破败礼拜堂 | Chapel / 主线 | 主线净化点、圣/血祭坛、导师真相；在终战前**解锁 Blood Mist Dash** 并教学（F16/R27） | 支持非战斗净化和换技能；主线谨慎路线有机会避免永久堕落 |

**房间设计防软锁约束**：02 旋转书架必须总有回到安全入口和墓穴主路的解法（可通过重置或有限稳定状态实现）；07 钟楼顺序输错只重置谜题不永久封门；03 血源只为**未开血印门**的必要血系交互补给，补给不产生 C，成功释放开门技能仍消耗 BP 并增加 C。

### 2.1 关卡回溯与锁定【已确认】

- 主线：`01 → 02 → 04 → 05 → 06 → 08`，支线 `03 / 07` 自愿探索（R62–65）。
- 已清除战斗房的 Cleared 状态永久保留；回溯不能重新刷房间敌人与一次性奖励（R15/R32）。
- 03、07 两处解药支线**直到玩家明确确认最终 Boss 之前**都可抵达，包括已经到达 08 准备区但尚未确认的时候（R68）。
- 在最终准备区确认后先锁定回溯；随后的导师对话中选择立场，立场一旦选定即持久保存。Boss 死亡重试后保留立场与封锁（F35=A），重试不要求重新选择。
- F18=A 为双向实体区域门和快捷门，**不增加任意检查点快速传送**。具体物理连接仍由关卡灰盒确定。

### 2.2 解药收集【已确认】

- 三份：05 主线 1 份，03/07 支线各 1 份；支线碎片不限定取得顺序（R57/R60）。
- 齐全是 Humanity 的**必要不充分条件**；必须战前拒绝力量、Boss 胜利提交后非 Permanent Fallen，才在战后服药（R69）。
- F22=A 的故事解释：Boss 存活时，导师通过王座将血之源的控制施加于感染者，解药不能有效解除感染；**击败导师解除其控制连接，但不等于毁灭血之源本体**。这样 Humanity 能完成治愈，Inheritance 仍可自愿继承未被毁灭的力量。

## 3. 资源、状态与 Corruption【已确认】

### 3.1 资源生命周期

| 资源 | 生效时点 | 核心约束 |
|---|---|---|
| HP | Human 起 | 死亡最近检查点满 HP 重生；首次触发检查点仅有限 HP 恢复，不得反复回血 |
| Blood / BP | Room 04 感染后 | Human 无 BP；血技能/主动血液再生耗 BP；普通攻击有效命中、击杀、精华、限定补给获取 |
| Corruption / C | Human 可由剧情**隐藏累计**（F02=B） | Human 不显示、不判 Fallen；感染后显示、开放 Fallen 判定；永久堕落后 C 锁上限 |

**数值模型**：采用 F03=A **固定增量 + 合理容错**。不根据当前 C 动态减免强制事件；支线净化增加容错，主线净化与最低必要血系动作必须存在谨慎可治愈路径。

- 原型 C 上限 **暂设 100（F29=A）**；正式 Cmax、Fallen 阈值 T、各来源固定增量仍需平衡。**100 是原型配置而非不可调整的正式数值；不要默认为 Cmax=T，除非测试配置明确如此设定。**
- `CommittedC` 表示所有持久已提交污染，包括 Human 隐藏值、感染事件、故事与祭坛；`PendingCombatC` 表示当前未胜利战斗中的成功血技能/血液再生增量。
- `EffectiveC = clamp(CommittedC + PendingCombatC, 0, Cmax)`。Human 即使有 C，也**不进入 Fallen**；感染事件后首轮计算必须确保低于 T。
- 战斗中仅由 pending 达阈值 → Temporary Fallen；胜利提交 pending，并按阈值永久锁定；战斗失败/退出丢弃 pending、撤销临时形态（R16–17、R82）。
- **落实解释**：战斗外成功释放血系能力或血液再生时 C 直接进入 CommittedC。剧情/祭坛等永久事件尽量只在非战斗触发，避免与 pending 竞态。
- Permanent Fallen 不可逆，普通净化和药剂不能恢复；只有未永久堕落者且满足结局条件，才可战后由完整解药恢复 Human（R05/R69）。

### 3.2 玩家形态

| 状态 | 技能与攻击 | 恢复/资源规则 |
|---|---|---|
| Human | 猎人武器、基本 Dodge；逐步解锁圣系 A、B | 药剂正常；无 BP、血技能、精华吸收；C 隐藏累计但不判 Fallen |
| Infected | A/B 分别可在非战斗切换圣/血版本；可吸精华、血液再生 | 人类药剂药效降低；血技能耗 BP 和增加 C |
| Temporary Fallen | 基础攻击变免费血爪/血刃，A/B 自动变血系；切换不刷新技能冷却 | 药剂暂禁，血液再生略增强，BP 容量暂提升；失败回滚状态 |
| Permanent Fallen | 永久血系主动技能，圣系主动能力禁用；旧圣系成长部分变通用属性（F32=A） | 药剂永久禁用但不删除库存；净化无法恢复人性；BP 最大容量提高，可进一步血系成长 |

- F33=A：临时容量结束时，当前 BP 超出恢复后上限的部分直接裁剪；不返还为其他资源。
- F32=A：圣系永久强化按**配置比例**变为通用攻击力/最大 HP 等被动属性，保持已经花费的一次性升级记录，不重购；具体清单与系数待调参。
- Fallen 血爪命中仍能获取 BP；高级技能耗 BP，永久 Fallen 状态下不会再增加 C。

### 3.3 关键资源防死锁

1. 05、08 **强制血系战斗**开始时补至一次必要技能所需 BP 的最低值（若不足），不能通过反复开启准备区堆叠（R30）。
2. 08 战斗中设计普通攻击可命中的补 BP 窗口，以及周期性场地 BP 补给（R24/R72）；05 精英破盾期间也必须可获得 BP。
3. 03 **非战斗机关**采用环境血源，恢复到开门必需技能费用的低阈值（F04=B/F30=A），可以重复使用但**只补至阈值，不叠加**；门一旦永久打开就永久停用，且该血源不能作为无上限回血站。
4. 未来如果另加“缺 BP 无法继续主线”的机关，需提供对应资源来源，并检验不可因已经 Cleared 而缺资源；不得直接凭空省略血系代价。

## 4. 输入、移动与交互【已确认】

### 4.1 鼠标/键盘一致性

| 输入/事件 | 规范 |
|---|---|
| 左键点击地面 | 自动 NavMesh 寻路，朝地点移动 |
| 左键点击敌人 | 锁定目标，自动接近范围并**持续普通攻击**（F06=A），不是自动释放技能 |
| 目标移出攻击范围 | 未使用 WASD 时恢复自动追击 |
| WASD 按下 | 立即接管移动，中断自动寻路，**暂停普通攻击，保留锁定目标**（F07=A） |
| WASD 松开 | 不恢复旧寻路；目标在当前攻击范围内可恢复普通攻击，超范围只保留锁定 |
| 左键点击其他位置/敌人 | 清除或更换旧追击目标，启动新目标行动 |
| 普通互动对象 | 左键点击，自动靠近并执行（F09=A） |
| 尸体精华 | 左键点击仅用于靠近、选中；进入范围后**长按 E 启动吸收**（F09=A） |
| Skill A | **鼠标落点**指定圣水/血爆范围（F08=C），与普通攻击锁定互不干扰 |
| Skill B | **鼠标方向**冲刺；鼠标指向有效敌人则朝该目标精准冲刺（F08=C） |

**输入优先级**：阻挡输入的 UI > 有效敌人 > 明确交互对象/精华 > 地面；无效/不可达目标不得让自动寻路持续卡死。统一 `PlayerMovementController` 为 Transform/Agent 的唯一位移仲裁者，WASD 优先于 NavMesh（R78/R81）。

**F36=B 可达性策略**：点击目标无完整路径时，尝试到最近**安全、真实可达**的 NavMesh 位置，提示目标无法直接到达；不可隔着锁门、未解谜通路、悬崖或敌方阻挡发生穿墙互动/攻击。到达最近点之后**停止**，不进入无限寻路与虚假攻击循环。

### 4.2 动作交错与攻击恢复

- F13=A：Skill A/B 动作结束时，若尚有合法锁定目标、在攻击范围内且未被 WASD 接管，则自动普通攻击恢复；不得刷新攻击间隔或技能 CD。正在进行技能、Dodge、治疗时不得同时发出普通攻击伤害。
- 基础 Dodge：短距离、防御性位移、有相对更长 i-frames、不消耗 BP、无 Corruption（F05=B）。
- Skill B：攻击型较长冲刺；Silver Dash 沿途圣系伤害；Blood Mist Dash **穿过敌人**且沿途血系伤害；**起步短 i-frames**，但时长明显短于 Dodge（F05=B/F12=B）。既有 i-frames 与攻击释放时点均需独立调参，不能因为多个碰撞回调而多次结算 BP/C。
- Skill A：Holy Water 范围伤害、短暂限制普通敌人行动；Blood Burst 高伤害范围爆发、能破特定血盾（F11=A）。Boss 控场抗性必须单独处理，不允许无限定身。
- 受击中断未正式释放的攻击或技能；技能未 Release：不扣 BP、不增 C、不进 CD；正式 Release 之后弹体/命中区域继续有效。形态切换继承 A/B 剩余 CD（R26、R46–47）。
- 三种治疗：药剂、尸体精华、主动血液再生相互排斥；进入引导后**无法主动取消**；仅完成、被有效攻击打断或死亡终止。成功才支付相应消耗并恢复 HP/BP；中断零扣费零恢复（R37/R41/R44）。

## 5. Combat 与敌人 AI【已确认】

### 5.1 三种基础敌人（F10=B）

| 敌人 | AI 主要状态与距离反应 | 两类主招及变招示例 | 玩家反制 |
|---|---|---|---|
| Blood Thrall 血仆 | 近距离追击、贴身攻击；按距离切换轻击/压迫 | 单挥击 → 二连击；中距离接近后可接终结扫击 | 基础 Dodge 防御；圣水短控场 |
| Blood Beast 血兽 | 中距离蓄力扑击、近距离抓击；攻击后有喘息窗口 | 快速抓击 / 可读招扑击；可按距离做连续扑击变化 | 观察前摇、闪避突进、抓后反击 |
| Elite Vampire 精英吸血鬼 | 具有护盾状态；按距离决定重击、护盾压迫或短位移 | 重击 / 血盾攻防，破盾后有短脆弱窗口；允许距离条件变招 | Blood Burst 破盾 + 及时输出 |

**复杂度边界（F10=B 的落实解释）**：三种敌人各自独立决策 AI，可复用 Health、Damage、Hitbox、NavMesh 感知和状态效果组件；“更多变招”不等于无限新增敌种或独立 Boss。具体攻击帧、波次与数值待测试，优先保证每次致命攻击有可读预警与反制窗口。

### 5.2 战斗房事务与奖励

- 普通战斗房 `Idle → LockedCombat → Cleared`；强制血系战房 `Preparation → RequiredSkillCheck → LockedCombat → Cleared`；装备不满足要求时不可锁门开战（R29）。
- 战斗胜利时依序处理 pending C、Permanent Fallen 判定、Cleared 与首次战胜奖励并安全保存；Boss 额外执行最终结局判定。
- 失败或中途退出视为本次挑战失败：敌人位置、HP 和临时攻击状态重置；pending C 丢弃；已提交剧情、祭坛、净化、已消费药剂、已拾取的持久物品及永久 Fallen **均保留**（R82/F38=A）。
- **一次性奖励防重复**：敌人击杀奖励、掉落物及尸体精华按稳定敌人/奖励 ID 记录唯一领取状态；失败重试可重生战斗实体，但**不得重新产生已经领取/消耗/永久过期的唯一奖励**。普通攻击的有效命中 BP 可按战斗实时结算；失败重生时 BP 重置为基准比例，不通过反复失败累积。
- **首次 Cleared 时尸体精华**：仅对尚存在且未消费、未过期的精华停止倒计时并永久保存；过期物不复活，已吸收物不再出现（R33–34）。
- **落实解释**：战斗失败后在下次挑战内，对于上次已生成但未消费的临时精华，究竟保留何种临时表现由持久状态机决定；无论采用何种实现，都必须满足“单敌唯一精华奖励不可重复、已消耗/过期不恢复、Cleared 时仅保存现存精华”。该时序需自动化测试。

### 5.3 Boss — Elias Voss（F19=A）

**同一套两阶段 Boss**，不另做独立分支 Boss。

- 第一阶段 **Hunter's Legacy**：猎人武器、银刃进攻、冲刺斩、少量血术；讲述师徒学过同一套战法。
- 第二阶段 **Blood Source Awakening**：血爪、血雨区域危险、血锁机制、周期 BP 地形补给；玩家必须以 **Blood Mist Dash 穿过指定血锁**，解除防护或创造击中窗口（F16=A）。
- 若玩家尚未解锁/装备必要的 Blood Mist Dash，战前 Preparation 必须先解锁、允许换装并检查；Fallen 自动血系化仍可使用。
- Blood Mist Dash 对普通敌人的穿透不等于可穿所有墙；**仅可穿过明确标记的血锁机制**，其他实体墙仍碰撞，避免路线上非法穿越。
- Boss 一阶段和二阶段都必须为普通攻击提供足够命中窗口；周期 BP 补给不等于可无限领取其他永久奖励。
- 战前接受/拒绝改变部分技能、台词、特效或参数，但不改变 Boss 主框架（R51/R58）。

## 6. 治疗、净化、强化、检查点【已确认】

### 6.1 治疗与一次性资源

| 途径 | 条件与效果 | 关键状态 |
|---|---|---|
| 普通药剂 | Human 正常；Infected 减弱；Temporary/Permanent Fallen **不能使用但仍保留背包物品** | 饮药成功才消耗一次，可被有效受击打断 |
| 敌人尸体精华 | 感染后长按 E 吸收，恢复主要 HP + 少量 BP，**不增加 C** | 每敌人一次；战斗期间有过期；Cleared 后未过期精华永久保留 |
| 主动血液再生 | 感染后独立按键；消耗 BP、恢复 HP，Infected 增 C；Fallen 回血效率略提高 | 引导成功才提交；受击中断不扣费、不回复 |
| 检查点一次性药剂 | 部分检查点首次激活提供一次领取资格 | **背包已满时保留待领取状态**；腾出空间后回来领取一次（F31=A） |

### 6.2 祭坛与净化

- 感染后每个强化祭坛只能用一次，圣系/血系二选一；圣系永久强化并降低 C，血系更强永久强化并增加 C（R06–09）。
- 主线固定净化点每点仅一次，支线携带式净化圣物只能非战斗使用、消耗后不再刷新。具体净化点数量/位置只以实际场景配置为准；**06 至少存在主线净化机会**。
- F29=A 首轮平衡必须检查：主线必遭遇剧情污染与最低必要血技消耗，在到达 06 首个已定义主线净化点**之前**不应因这些不可避免事件永久堕落，并且在合理使用主线净化后谨慎路线仍保留安全余量；建议以阈值的约 **20%** 作为初次测试目标，**此余量是验收候选值，非已确认正式难度数字**。
- Permanent Fallen 不再获得圣系净化，不可以通过任何普通圣物逆转。

### 6.3 检查点与失败重生

- 检查点首次激活有限 HP 恢复；部分一次性药剂领取资格；再次走到同一地点不得重复回血/补药（R38–39）。
- 死亡重生最近激活检查点，HP 满值、BP 设置为该形态 BP 上限的一定**基础比例**（示例 20% 仍待调参），Human 无 BP（R40）。
- 重要检查点在感染前后、礼拜堂、最终 Boss 前，具体布置待关卡测试（R67）。

## 7. 三结局与状态优先级【F01=A 已确认】

### 7.1 唯一判定

胜利后先提交本次战斗 pending C，锁定新 Permanent Fallen，随后**依据战前永久形态快照和立场**处理结局，保证只产出一个 EndingID。

| 判定优先级 | 条件 | 结局 |
|---|---|---|
| 1 | **最终对话开始前**已 Permanent Fallen（快照值） | **Too Late**；可表态但无法治愈 |
| 2 | 战前未 Permanent Fallen，选择 **Accept** | **Inheritance**；即使 Boss 战中新增 Permanent Fallen 也不改成 Too Late |
| 3 | 战前未 Permanent Fallen，选择 **Reject**，三份解药齐全，Boss 战结束结算后仍未 Permanent Fallen | **Humanity**；战后服药 |
| 4 | 其余（包括拒绝力量但缺碎片，或拒绝且终战新 Permanent Fallen） | **Too Late** |

- **绝不允许**以战斗最后一帧的 Temporary Fallen 外观覆盖战前立场；F01 优先级是游戏规则。
- Too Late 具有两个叙事表现子类型，但只有**一个 EndingID**：永久 Fallen / 缺少解药（可能尚未 Permanent Fallen）。缺碎片不得强行将 C 改到上限。
- F35=A：最终确认封锁回溯时保存 `FinalArenaLocked`，首次对话开始前保存 `PreBossPermanentFallen`，选择接受/拒绝后保存 `FinalStance`；死亡重试不能重置已完成的这些记录。若意外在锁定后、完成立场选择前退出，恢复时必须继续立场对话，不能进入未选择状态的 Boss 战。
- Ending 不在战斗失败时提交；只在 Boss 真正胜利后执行。不同结局使用同一套两阶段 Boss 框架。

- 发生崩溃时不得出现“物品已给但状态未保存/存了 Cleared 却没保存 C”的半事务；对同一次结算先更新内存事务，再持久化完整一致快照。实际写盘策略列入 Plan 实施测试。

## 10. 数值原型与验收测试

### 10.1 关系式（非最终正式数值）

```text
0 <= HP <= MaxHP
Human: BP system disabled; CommittedC may be hidden; Fallen transition disabled
Infected/Fallen: 0 <= BP <= MaxBP(CurrentForm, UpgradeState)
0 <= CommittedC <= Cmax
EffectiveC = min(Cmax, CommittedC + PendingCombatC)
OnBloodSkillRelease: BP -= Cost; if Infected -> C += FixedGain (pending in combat, committed out of combat)
OnInterruptBeforeRelease: no BP cost, no C change, no CD
OnCombatVictory: commit pending C; determine PermanentFallen; mark Cleared; save coherent snapshot
OnCombatFailureOrExit: clear pending C; remove temporary-only Fallen; keep permanent world events; respawn checkpoint
PreBossPermanentFallen = snapshot before final dialogue
EndingID = choose once, based on pre-boss snapshot, stance, fragments, post-victory PermanentFallen
```

**测试指标**：在初始 Cmax=100 的配置下验证累计强制剧情增量、05 Blood Burst 一次必要成本、08 Blood Mist Dash 一次必要成本、主线净化量与玩家主动使用的固定成本；逐节点 `CommittedC + PendingC` 必须能让理性玩家最终治愈，且分支净化增加但不承担唯一必需的救命资源。正式敌人和 BP/CD/HP 量可调。
