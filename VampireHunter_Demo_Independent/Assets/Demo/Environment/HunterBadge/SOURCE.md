# Original hunter cross badge

Created for this project on 2026-11-06 (Asia/Shanghai), following the user's request for a free badge or cross-type clue.

Original project geometry generated in Unity by ClueDetailSetup.cs: a layered metal badge body, raised cross, four rivets and a suspension eye. No external model, image, paid package, network installation or purchase was used. The mesh has 620 triangles and uses three project-created URP materials.

Reusable model: Hunter_Cross_Badge.prefab, with meshes and materials beside it. Current scene instance is scaled to 0.68 and lies on the terrain near the original emblem clue. The visual cross is a Demo art proposal, not an approved final-game lore or system rule.

Traceability: R53/R59, F23/F24/F27; Narrative v2 section III. Existing emblem clue identity, range and investigation flow are preserved.
