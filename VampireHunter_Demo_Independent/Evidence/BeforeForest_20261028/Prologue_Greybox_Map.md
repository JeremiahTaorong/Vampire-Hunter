# 独立 Demo — 序章地图与调查灰盒

状态：待人工走图；几何体是空间草案，不是正式美术。尺寸为 Unity 单位，未校验实际行走时间。

```text
村庄进入点 → 失踪现场 → 村庄广场 / 证人
                  ↓              ↓
            导师纹章物证     交谈获得证词
                  └── 村口拖拽痕迹 ──┐
                                   ↓
                           简单推理：选择森林
                                   ↓
                     林地入口地标 → 森林外围遭遇区
                                   ↓
                         击败敌人 → 导师标记 → 古堡方向
```

| 区域 | 空间设计与用途 |
|---|---|
| 村庄入口 / 现场 | 玩家从西侧进入；现场旁是纹章物证，房屋体块提示调查地点。 |
| 村庄广场 | 以中央井形体块和房屋形成方向地标；证人位于广场另一侧，需主动前往。 |
| 村口 | 村口的拖拽痕迹是第三条线索；三个对象分散摆放，可自由调查顺序。 |
| 林地入口 | 南北两侧障碍保留中间开口，形成可见的区域转换；提示面板说明森林在画面右侧。 |
| 森林外围 | 数个大体块提供树木占位与空间节奏；敌人只在正确推理后出现，死亡后导师标记出现。 |
| 远景 | 大型体块提示古堡方向；目前不具备可进入的古堡和正式远景演出。 |

地面约 120 × 64 单位，入口到森林敌人直线距离约 78 单位；村庄线索在不同位置。数量不是最终尺寸，也不保证试玩时长；须根据 5–8 分钟目标、实际路线、战斗与对话节奏调整。边缘尚无正式美术遮挡、地图界面、完成的建筑内部、过场或完整故事。

解谜条件：纹章、证词、拖拽痕迹齐全后才能做推理；错误选择可重试。正确选择激活敌人；击败敌人才显示导师标记，调查标记后结束；重试从场景初始状态开始。文字为英文草案，尚待正式润色。
